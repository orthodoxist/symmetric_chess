# 대칭 체스 10×10

`index.html`을 브라우저에서 열면 설치 없이 컴퓨터와 대결하거나 두 사람이 한 기기에서 플레이할 수 있습니다. 대국 설정에서 방식을 선택하고, 컴퓨터 대결에서는 내 진영(백·흑)과 난이도(쉬움·보통·어려움)를 고른 뒤 대국 시작을 누릅니다. 설정을 바꾸려면 새 게임을 누릅니다.

컴퓨터는 브라우저에서 기물 가치·이동성·폰 전진·마지막 킹의 안전을 평가합니다. 쉬움은 최대 3초·3단계, 보통은 최대 6초·5단계, 어려움은 최대 10초·12단계까지 탐색합니다. 어려움은 이전 매우 어려움의 탐색 방식으로, 후보 수 제한 없이 포획·프로모션 연쇄를 추가 분석합니다. 실제 완료 깊이와 생각 시간은 배치와 기기 성능에 따라 달라지며 명확한 승리나 탐색 완료 시 일찍 응답할 수 있습니다. 남은 대국 시간이 적으면 계산 시간을 줄입니다. 계산 중에도 화면과 시계는 동작하며 새 게임이나 시간패 시 계산을 취소합니다. 인터넷이나 외부 API 키는 필요하지 않습니다.

백부터 시작하며 R은 룩입니다. 상대 킹 두 개를 모두 포획하는 것을 목표로 하며, 마지막 킹의 포획 위험을 남기는 수는 금지합니다. 캐슬링과 앙파상은 없습니다. 폰은 첫 이동에 경로가 모두 비어 있으면 1·2·3칸 전진을 선택할 수 있고 이후에는 1칸씩 전진합니다. 포획은 대각선 1칸입니다. 폰이 끝 행에 도착하면 포획된 자신의 비폰 기물(킹 포함) 하나를 복귀시킵니다. 선택할 비폰 기물이 없다면 즉시 승리합니다.

규칙 검증: `node engine.test.js`

컴퓨터 검증: `node ai.test.js`

대국 모드·시계·새 게임 연동 검증: `node ai-ui.test.js`

웹 배포용 정적 파일 생성: `npm run build` (`dist/`에 게임 파일을 생성합니다). 테스트 전체 실행: `npm test`.

첫 화면에는 대국 설정(플레이어별 제한시간 포함)과 게임 규칙만 표시됩니다. 대국 시작을 누르면 체스판과 남은 시간·이동 기록·포획 기물이 표시되는 대국 화면으로 전환합니다. 새 게임은 진행 중 대국의 종료를 확인한 뒤 설정 화면으로 돌아가며, 다음 대국 설정을 다시 선택할 수 있습니다.

현재 차례인 플레이어의 킹이 하나만 남았을 때, 그 킹이 이동한 직후 상대가 포획할 수 있는 이동 칸도 빨간색으로 표시합니다. 상대 차례에는 자신의 킹 이동 위험 칸을 표시하지 않습니다. 이동 후의 배치와 비숍의 대각선 공격 경로 변화를 계산하며, 위험 칸으로의 이동은 금지됩니다.

색 표시는 현재 차례인 플레이어가 이번 수에 승리할 기회와 상대의 다음 수에 패배할 위험을 함께 표시합니다. 마지막 킹을 포획할 수 있는 기물의 칸은 밝은 초록색, 포획될 킹의 칸은 밝은 빨간색입니다. 프로모션 즉시 승리가 가능하면 폰의 칸은 초록색, 마지막 랭크 도착 칸은 빨간색입니다. 두 표시가 겹치면 두 색으로 나눠 표시합니다. 킹의 위험한 이동 칸은 현재 차례인 플레이어에게만 표시합니다. 별도 글 알림이 없으므로 체스판 위치는 바뀌지 않습니다. 실제 위험은 현재 플레이어의 이동에 따라 달라질 수 있으며, 표시된 위험을 남기는 이동은 이동 가능 목록에서도 제외됩니다.

비숍은 일반 체스처럼 대각선으로 원하는 거리만큼 이동하며 중간 기물을 뛰어넘을 수 없습니다. 도착 칸의 적 기물을 포획하며 아군 기물이 있는 칸에는 이동할 수 없습니다.

현재 시험 버전의 나이트는 기존 체스처럼 가로·세로 2칸과 1칸으로 이동합니다. 중간 기물을 뛰어넘으며 도착 칸의 상대 기물만 포획합니다. 화면의 100점 배분에서 나이트는 5점이며 AI 내부 나이트 기본 평가는 3.3폰입니다. 강화 나이트 버전은 GitHub 변경 이력에서 복구할 수 있습니다.

무승부는 동일 포지션 5회 반복 또는 폰 이동·포획 없이 50수(양쪽 각각 50회, 총 100회 행마)에서 자동으로 판정합니다. 반복 판정에는 이동 차례, 기물 배치, 프로모션 가능한 포획 기물 구성이 포함됩니다. 스테일메이트는 해당 플레이어의 즉시 패배로 판정합니다. 다른 무승부 판정은 없습니다.

대국 시간은 플레이어별 15분+0초, 30분+0초, 45분+0초 중 선택합니다. 대국 시작 버튼을 누르면 백의 시계가 시작되며, 자기 차례에만 시간이 줄어듭니다. 프로모션 선택 중에도 시간이 흐르고 0초가 되면 즉시 시간패합니다.
마지막 킹이 공격받고 어떤 이동·포획·차단·프로모션으로도 다음 수의 킹 포획을 피할 수 없으면 체크메이트로 즉시 패배합니다. 공격받지 않아도 둘 수 있는 수가 하나도 없으면 스테일메이트로 즉시 패배합니다. 마지막 킹의 포획 위협 또는 상대의 즉시 프로모션 승리를 남기는 수는 허용되지 않습니다.

승리 화면에는 체크메이트 승리·스테일메이트 승리·프로모션 승리·시간승을 구분해 표시합니다. 마지막 킹이 공격받으며 합법적인 수가 없으면 체크메이트, 그 외에 합법적인 수가 없으면 스테일메이트 패배입니다. 프로모션 선택도 상대의 즉시 승리를 허용하지 않는 기물로 제한됩니다.


남은 기물 점수: 폰 2, 나이트 5, 비숍 6, 룩 9, 퀸 15, 킹 5점으로 양측 100점부터 시작합니다. 킹을 포함해 현재 체스판에 살아 있는 20개 기물을 합산합니다. 프로모션 시 폰을 빼고 복귀 기물의 점수를 더합니다. 대국 시간 아래에 점수를 표시하며 이동 기록은 시간 옆에 배치합니다. 포획한 기물에만 !를 약 2초 표시합니다. 상대가 다음 수에 포획할 수 있는 모든 아군 기물을 검사하며, 방금 잡은 적 기물과 같거나 높은 점수의 아군 기물이 하나라도 잡힐 수 있으면 표시하지 않습니다. 포획 가능한 아군 기물이 없거나 낮은 점수의 기물만 잡힐 수 있으면 표시합니다. 킹 포획 위험이 있으면 표시하지 않습니다. 다른 말풍선 규칙은 없습니다. 검증: node material.test.js.

## 온라인 대결

대국 설정에서 온라인 대결을 선택합니다. 방장은 진영과 제한시간을 고르고 방 만들기를 누른 뒤 초대 링크를 상대에게 전달합니다. 상대는 링크를 열고 방 입장을 누릅니다. 두 사람이 연결되면 시계와 대국이 시작됩니다. 기존 GitHub Pages에서 사용하며 PeerJS Cloud의 무료 연결 서버와 WebRTC 데이터 연결을 이용합니다. PeerJS 1.5.5는 온라인 모드 진입 시 jsDelivr에서 불러옵니다. 별도 계정이나 카메라·마이크 권한은 필요하지 않습니다.

방장의 브라우저가 이동의 합법성, 차례, 프로모션, 승패, 제한시간을 검증합니다. 방장 창을 닫거나 새로고침하면 방과 대국이 사라지므로 대국 중에는 열어두세요. 상대방은 같은 브라우저 탭에서 새로고침한 뒤 동일 링크로 재입장하면 기존 대국에 다시 연결할 수 있습니다. 연결이 끊겨도 시계는 계속 진행됩니다. 일부 회사·학교 네트워크나 NAT에서는 연결이 제한될 수 있습니다. 그 경우 다른 네트워크를 사용하거나 별도 TURN 중계 서버를 추가해야 합니다. 공개 연결 서버는 서비스 장애 영향을 받을 수 있으며, 방장 브라우저를 권위로 사용하는 친선 대국 방식이므로 경쟁전용 부정행위 방지 서버는 아닙니다.

검증: node online.test.js. 실제 Chromium 두 페이지와 공개 PeerJS 서버를 이용해 초대, 쌍방 이동, 차례 제한, 상대 새로고침 재접속, 원격 프로모션을 검증했습니다.

## Two games

컴퓨터와 대결·사람과 대결에서 경기 구성을 Two games로 선택하면 같은 제한시간과 상대를 유지하며 두 판을 진행합니다. 첫 판이 끝나면 두 번째 판 시작을 누르며, 온라인에서는 두 플레이어가 모두 준비해야 시작합니다. 두 번째 판은 진영을 바꿉니다. 승리 +1, 무승부 0, 패배 -1을 합산하고 점수가 같으면 각 플레이어의 두 판 사용시간(제한시간에서 남은 시간을 뺀 값)을 합산한 뒤 소수점 이하를 버린 정수 초로 비교합니다. 더 적게 사용한 플레이어가 이기며 정수 초도 같으면 최종 무승부입니다. 결과 공유에는 각 판 결과와 종합 결과가 포함됩니다. 검증: node series.test.js.

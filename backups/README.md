# 저장된 기준 버전

## 2026-10-03-symmetric-10x10-v1

2026년 10월 3일 확정된 대칭 체스의 실행 파일, 규칙 설명, 테스트를 보관합니다. 이 폴더의 파일은 향후 실험 시 수정하지 않습니다. 실험은 프로젝트 최상위 폴더에서 진행합니다.

- 10×10, 초기 배치 R N B Q K K Q B N R 및 폰 10개
- 체크 제한 없이 두 킹을 모두 포획해야 승리
- 캐슬링·앙파상 없음
- 폰 첫 이동 1·2·3칸, 이후 1칸; 전진 경로가 모두 비어 있어야 함
- 포획된 자신의 비폰 기물로만 프로모션(킹 포함); 선택지가 없으면 즉시 승리
- 무승부는 3회 반복 또는 폰 이동·포획 없이 양쪽 각각 30수
- 플레이어별 15·30·45분, 추가 시간 없음; 시간 소진 시 시간패
- 판 밖 좌표, 포획 기물, 이동 기록, 프로모션 선택 화면 포함

백업 폴더의 `index.html`을 브라우저에서 열면 이 버전을 바로 플레이할 수 있습니다.

# 대칭 체스 10×10

`index.html`을 브라우저에서 열면 설치 없이 두 사람이 한 기기에서 플레이할 수 있습니다.

백부터 시작하며 R은 룩입니다. 체크 제한 없이 상대 킹 두 개를 직접 포획합니다. 캐슬링과 앙파상은 없습니다. 폰은 첫 이동에 경로가 모두 비어 있으면 1·2·3칸 전진을 선택할 수 있고 이후에는 1칸씩 전진합니다. 포획은 대각선 1칸입니다. 폰이 끝 행에 도착하면 포획된 자신의 비폰 기물(킹 포함) 하나를 복귀시킵니다. 선택할 비폰 기물이 없다면 즉시 승리합니다.

규칙 검증: `node engine.test.js`

무승부는 동일 포지션 3회 반복 또는 폰 이동·포획 없이 30수(양쪽 각각 30회, 총 60회 행마)에서 자동으로 판정합니다. 반복 판정에는 이동 차례, 기물 배치, 프로모션 가능한 포획 기물 구성이 포함됩니다. 스테일메이트를 포함한 다른 무승부 판정은 없습니다.

대국 시간은 플레이어별 15분+0초, 30분+0초, 45분+0초 중 선택합니다. 대국 시작 버튼을 누르면 백의 시계가 시작되며, 자기 차례에만 시간이 줄어듭니다. 프로모션 선택 중에도 시간이 흐르고 0초가 되면 즉시 시간패합니다.
